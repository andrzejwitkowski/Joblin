# i18n (pl / en / de) — design

## Goal

Localize Recruit OS UI chrome and known API error messages into Polish, English, and German.

## Decisions

- Stack: `i18next` + `react-i18next` + `i18next-browser-languagedetector`
- Locales: `pl` | `en` | `de`
- Preference: `localStorage` (`joblin-locale`) → browser → **fallback `en`**
- Invalid / unknown / foreign stored or browser locale → `en`
- Language switcher in Shell header; login follows storage/detector only
- Offer/ingest body content not translated
- Backend API messages stay English; frontend maps known strings to `errors.*`

## Architecture

- `frontend/src/i18n/` — init + `locales/{pl,en,de}.json`
- `document.documentElement.lang` synced on language change
- `translateApiError()` for user-visible API/boot errors
